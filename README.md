# Portfólio | Lucas Eduardo Alves

Next.js 15 (App Router) + TypeScript.

## Como rodar
```bash
npm install
npm run dev
```

## Como personalizar
- Todo o texto, projetos e links ficam em `data/content.ts`.
- Coloque sua foto em `public/assets/profile.jpg` (sem ela, aparecem suas iniciais).
- Troque `whatsapp` em `data/content.ts` pelo seu número (DDI + DDD + número).
- Cores e tipografia: variáveis no topo de `app/globals.css`.

## Deploy
Envie para o GitHub e importe o repositório na Vercel.
